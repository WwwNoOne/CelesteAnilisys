# Archivos de referencia para reportes financieros

Estos archivos son referencias del resultado final de la aplicación. No forman parte de los archivos de entrada contable que se analizan en la Task 4.

## `ANALISIS Y RATIOS FINANCIEROS.xls`

Contiene información histórica de un balance general y ejemplos de indicadores financieros. Sirve como referencia para el futuro módulo de resultados y comparación de períodos.

Indicadores observados:

- Solvencia y prueba ácida.
- Endeudamiento sobre activos.
- Apalancamiento operativo, financiero y combinado.
- Indicadores basados en flujo de caja operativo.
- EBITDA y EBITDA sobre ventas netas.
- Productividad del capital de trabajo.
- Productividad del activo fijo.
- Palanca del crecimiento.

## `informacion de indicadores financieros.xls`

Funciona como catálogo conceptual de indicadores. Incluye nombre, fórmula o base de cálculo, unidad, clase de indicador y descripción.

Se utilizará posteriormente para diseñar un catálogo configurable de indicadores, evitando codificar las fórmulas directamente en la interfaz.
