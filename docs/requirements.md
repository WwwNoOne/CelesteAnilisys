# Requisitos iniciales

## Funcionalidades previstas

- Importar archivos de hojas de cálculo y datos delimitados.
- Revisar errores y advertencias antes de confirmar una importación.
- Guardar información financiera de forma estructurada.
- Consultar períodos mensuales y anuales.
- Comparar dos o más períodos.
- Generar indicadores, variaciones y reportes financieros.

## Preguntas pendientes

- ¿Qué estados financieros y columnas estarán presentes en los archivos?
- ¿Se importarán varios negocios, sucursales o centros de costo?
- ¿La aplicación será de un solo usuario o tendrá cuentas y permisos?
- ¿La base de datos será únicamente local o también podrá ser remota?
- ¿Qué reportes deben exportarse y en qué formatos?
- ¿Qué volumen máximo de filas se espera por archivo?
